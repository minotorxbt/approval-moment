Attack suite

Runs every demo proposal (honest, sloppy and malicious) through the verifier and compares the result with the answer a correct verifier should give. Back to the app

This is a regression check, not an independent benchmark: the fixed rules were written with these cases in view. A hidden-text rule that catches a new attack is a good sign, but the real test is attacks nobody has thought of yet. The AI run adds NEAR AI Cloud as a second opinion that can only make a verdict stricter.
